BEFORE YOU INSTALL

Clear dependencies, no bundled third-party water assets

The Core package uses Unity gameplay scripts and the Input System where required. The Water Add-on requires the Core package and a compatible installation of Crest Water. Crest files and third-party assets are not included in the add-on and must be obtained under their own applicable terms.

Check the package documentation for the supported Unity version, setup steps, and component references before integrating the tools.
